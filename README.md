# BELUQUERIA

Página web de la peluquería. Es HTML y CSS puro, sin dependencias.

## Archivos

- `index.html` — la página
- `aviso-legal.html` — aviso legal (LSSI) y créditos de fotos
- `privacidad.html` — política de privacidad (RGPD)
- `img/` — fotos de los cortes

Antes de publicar, completá los datos resaltados en amarillo en `aviso-legal.html` y `privacidad.html`.

## Publicar en GitHub Pages

1. Subí `index.html` e `img/` a un repositorio de GitHub.
2. En el repositorio, entrá a **Settings → Pages**.
3. En **Source** elegí **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guardá.
4. En uno o dos minutos la página queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Créditos de fotos

Fotos de Wikimedia Commons bajo licencias Creative Commons (detalle al pie de la página).
